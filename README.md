# SITU · Demo MVP

Prototipo académico en React + Vite basado en el alcance descrito en las Fases 3 y 4.

## Ejecutar localmente
1. Instala Node.js LTS desde https://nodejs.org/ si aún no está instalado.
2. Descomprime el proyecto y abre una terminal dentro de la carpeta `SITU_MVP_Demo`.
3. Ejecuta `npm install`
4. Ejecuta `npm run dev`
5. Abre en el navegador la URL local que muestre Vite (normalmente http://localhost:5173).

## Qué incluye
- Búsqueda por título, código y sinónimos de ejemplo (p. ej. “retirar materia”).
- Ficha estructurada con pasos y requisitos.
- Checklist interactivo con barra de progreso.
- Enlace externo al sitio general de ECCI.
- Diseño adaptable a escritorio y móvil.

## Límites y validación obligatoria
- Los trámites, requisitos y fechas son datos de demostración, no una fuente oficial verificada.
- El enlace conduce al sitio general de ECCI; debe reemplazarse por la URL exacta del procedimiento si el equipo la confirma.
- No incluye backend, base de datos, autenticación, persistencia de checklist, integración institucional ni radicación real.
- El prototipo local NO equivale a un despliegue en la nube.
- Antes de presentar, valida los datos con fuentes institucionales y prueba el flujo en el dispositivo de la demo.
